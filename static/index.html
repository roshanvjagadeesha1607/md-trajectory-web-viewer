Surface (NGL msms) — probe-based molecular surface. Built from the atoms currently transferred — in Cα/Backbone mode that is the trace only (tube-like envelope); switch to Full atoms for a true molecular surface. The mesh rebuilds whenever the frame changes, so playback works here: the grid is automatically coarse while playing and refined back to the selected quality when paused. Large systems (Full atoms) play slower. (Gaussian is a separate, smoother envelope.)
Gaussian Surface (QuickSurf-like) — a Gaussian density envelope, not a molecular surface: every protein atom contributes a smooth density blob and an isosurface of the summed density is meshed (splat + box-spline + marching cubes, computed in a Web Worker — the same splat/box idea as VMD QuickSurf, on CPU). It animates with the trajectory and is computed from the atoms currently transferred (Cα/Backbone = trace only; Full atoms for a scientifically meaningful envelope). While playing a coarse mesh keeps frames fast and it refines to the selected quality when paused. Ligands/ions stay visible via their own reps; water is excluded unless ticked.
